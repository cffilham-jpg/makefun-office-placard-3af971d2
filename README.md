A museum placard preserves a sticky note's urgent inscription long after its urgency has passed. This standard-library Python program writes the label as UTF-8 without a trailing newline.

## Run it

```sh
python3 main.py
```

Set MAKEFUN_OUTPUT_DIR to choose the output directory; otherwise the program uses out, with a temporary-directory fallback if needed.
